
# AFTERSAVE 0.4 и Steam

## Обновление на GitHub Pages

Сначала сохраните копию через **Настройки → Скачать JSON**. Если обновляете из ZIP, загрузите его содержимое в корень существующей ветки GitHub Pages с заменой файлов. После загрузки обновления закройте все вкладки AFTERSAVE и окно установленного приложения, затем снова откройте прежний адрес. Миграция сохраняет записи, коллекции и профиль по тому же адресу. Папка `worker/` содержит серверную часть для Cloudflare.

При первом импорте связываются однозначные совпадения среди ручных карточек PC и Steam Deck. Карточки других платформ и неоднозначные совпадения остаются отдельными. Повторный импорт обновляет только поля Steam. Часы Steam видны отдельно, а сводка по библиотеке учитывает большее из ручного и Steam-времени для каждой игры. Сюжетный прогресс, оценки, заметки, избранное и прохождения редактируются вручную. Старые записи прохождений сохранены во вкладке «Сессии». Новые записи с длительностью добавляются в ручной журнал сессий.

Доли игроков Steam и сортировка по редкости доступны после развёртывания обновлённого защищённого Worker, если Steam возвращает доли для игры. Достижения загружаются при открытии карточки, кэшируются в IndexedDB и затем доступны без сети. Сводка показывает, для скольких игр получены данные. Чтобы заполнить её по библиотеке, используйте **Обновить сводку достижений**. Приложение обращается к Steam последовательно. JSON включает пользовательские записи и привязки Steam. Кэш достижений можно заполнить снова.

Пока действует старый публичный Worker, используйте **Профиль → значок Steam → Публичный Worker**. Оно действует в текущем сеансе. Если достижения Elden Ring закрыты, проверка аккаунта в этом режиме прервёт импорт. После входа библиотека обновляется раз в 30 минут, пока приложение открыто и сеанс активен. Доступно и ручное обновление.

## Закрыть доступ к данным Worker

1. Откройте **Cloudflare Dashboard → Workers & Pages → aftersave-steam → Settings → Variables and Secrets**. Оставьте существующий секрет `STEAM_API_KEY`. Проверьте наличие `STEAM_ID` с вашим 17-значным SteamID64. Добавьте секрет `AFTERSAVE_PASSWORD` со случайным паролем от 24 символов. Сохраните пароль в менеджере паролей.
2. В папке `worker` выполните `npx wrangler@latest login` и выберите свой аккаунт Cloudflare. Затем выполните `npx wrangler@latest deploy --keep-vars`. Конфигурация Wrangler добавит две обязательные привязки для ограничения частоты запросов. Простая вставка кода в редактор Dashboard эти привязки не создаёт.
3. По прежнему адресу `/health` должен вернуть `{"ok":true}`. Прямые запросы к `/library` и `/achievements?appid=1245620` без токена должны вернуть 403 или 401. На GitHub Pages нажмите **Синхронизировать Steam**, введите настроенный пароль и проверьте загрузку. Старый тестовый режим после включения защиты выдаст ошибку доступа.
4. Для отзыва всех сеансов замените `AFTERSAVE_PASSWORD` в Dashboard.

Worker ограничивает браузерные запросы адресом `https://nkuzyanin-cloud.github.io`. Для доступа к данным нужен подписанный токен со сроком на час. Он находится в памяти открытой страницы. Пароль и Steam-ключ отсутствуют в GitHub и в файлах приложения. Worker привязан к одному SteamID и загружает достижения только для игр его библиотеки. Результаты кэшируются на сервере по аккаунту, а личные ответы не попадают в HTTP-кэш браузера.
