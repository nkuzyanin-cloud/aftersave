# AFTERSAVE 0.4

Личная игровая библиотека с обложками, прогрессом, оценками, заметками, коллекциями и статистикой. Работает на компьютере и iPhone. Приложение открывается без регистрации и подписки.

[Подключение Steam, обновление 0.4 и защита Cloudflare Worker](./worker/README.md)

## Полка и игровой журнал

«Моя полка» показывает добавленные вручную игры и игры с назначенным статусом. «Все игры» показывает полную видимую библиотеку. Скрытые игры можно вернуть в разделе «Скрытые». Синхронизация сохраняет ручные статусы и скрытие.

История прохождений доступна во вкладке «Сессии». Ранее сохранённый текст заметки появится отдельной записью во вкладке «Заметки». В JSON сохраняются сессии, заметки, полка и скрытие. Для переноса старой библиотеки на другой адрес восстановите её из JSON.

Синхронизация Steam доступна из профиля и настроек. Достижения по-прежнему загружаются по запросу. Процент игроков и сортировка по редкости включаются, если Worker передаёт эти данные.

## Опубликовать на GitHub Pages

1. Распакуйте ZIP. Откройте свой репозиторий на GitHub или создайте публичный репозиторий с веткой `main`.
2. На вкладке **Code** выберите **Add file → Upload files**. Перетащите содержимое распакованного архива, включая папку `assets` и файл `.nojekyll`, и нажмите **Commit changes**. В корне ветки рядом с `assets` должен лежать `index.html`. Если `.nojekyll` оказался скрыт при загрузке, создайте пустой файл с этим именем через **Add file → Create new file**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, затем **main** и **/(root)**. Нажмите **Save**.
4. Дождитесь публикации и нажмите **Visit site** на странице **Settings → Pages**. Адрес проекта обычно выглядит как `https://ваш-логин.github.io/имя-репозитория/`.

При обновлении загрузите файлы из нового ZIP с заменой в ветку и папку, выбранные в **Settings → Pages**. Откройте сайт с интернетом. После загрузки обновления браузер применит его, когда закроются все вкладки сайта и окно установленного приложения. На прежнем адресе сохранения остаются в браузере.

[Публикация из ветки в GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Загрузка файлов через GitHub](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## Установить и открыть офлайн

- **iPhone.** Откройте сайт в Safari. Нажмите **Поделиться → На экран «Домой»**, включите **Открыть как веб-приложение**, если есть такой переключатель, и нажмите **Добавить**. Если уже вели библиотеку в Safari, скачайте JSON в настройках, затем импортируйте его в приложение, открытое с экрана «Домой». [Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iph42ab2f3a7/27/ios/27) · [Как Safari хранит данные веб-приложений](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)
- **Компьютер.** В Chrome или Edge воспользуйтесь значком установки в адресной строке или соответствующим пунктом меню браузера. Вкладка браузера тоже подходит.
- Первый запуск, в том числе из нового значка на iPhone, сделайте с интернетом. Приложение загрузит файлы и обложки встроенного каталога. Когда в настройках появится сообщение о готовности офлайн-режима, библиотеку можно открывать без интернета по тому же адресу.

## Начать библиотеку и сохранить копию

Встроенный каталог содержит подборку игр, среди которых Elden Ring, Days Gone, Deadpool и Euro Truck Simulator 2. Найдите игру по названию или воспользуйтесь ручным добавлением для любого издания и платформы. Кнопка «Поиск в Wikidata» отправляет поисковый запрос в Wikidata и требует подключения к интернету. Обложки, добавленные по внешней ссылке, тоже загружаются через интернет. При первом запуске видны демо-примеры. Нажмите «Мои игры», чтобы открыть личную библиотеку.

Ваша библиотека хранится в данных сайта в этом браузере. Для переноса на другой браузер, устройство или адрес сайта сохраните JSON и импортируйте его на новом месте. Импорт JSON заменяет текущие записи, коллекции и профиль, поэтому перед восстановлением можно сохранить текущую копию. Для просмотра в таблице есть экспорт CSV.

Храните JSON отдельно от сайта, например в папке «Документы». Очистка данных сайта и удаление приложения могут стереть локальную библиотеку. Публикуются файлы приложения, а ваш прогресс остаётся в браузере. Steam можно подключить через Worker. Записи PlayStation Network и Xbox ведутся вручную.

## Открыть локально

Если установлен Python, откройте терминал в распакованной папке и запустите `py -m http.server 8000` на Windows или `python3 -m http.server 8000` на macOS. Откройте `http://localhost:8000/`. Такой запуск позволяет проверить установку и работу без сети. На GitHub Pages для этого используется HTTPS.
